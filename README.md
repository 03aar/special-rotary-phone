# LOOP - Context Intelligence Training Platform

> Where human learning meets machine understanding

## Overview

LOOP is a web-based application designed to train users in context intelligence—the ability to communicate effectively with AI systems by understanding how machines interpret human language.

## Features

- **Interactive Onboarding**: Engaging entry experience with baseline assessment
- **Mission-Based Learning**: Context challenges across clarity, emotion, bias, and logic
- **Real-Time AI Analysis**: Instant feedback with AI attention heatmaps
- **Progress Tracking**: Context IQ scoring and skill progression
- **Beautiful Design**: Minimalist interface with thoughtful animations

## Technology Stack

- **Framework**: React 18
- **Routing**: React Router v6
- **Build Tool**: Vite
- **Styling**: CSS Modules with design system
- **Deployment**: Ready for Vercel/Netlify

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.

### Build for Production

```bash
npm run build
```
